# Dummy sample files

All names, orders and buyers in these files are made up. Use them to try the import
screen without real data. Each file is in the same layout as that platform's own download.

| File | Pretend store | Looks like |
|---|---|---|
| ebay-orders-sample.csv | RetroLoot (retro gaming) | eBay Seller Hub orders report |
| amazon-all-orders-sample.txt | Kitchen Nook (kitchen gadgets) | Amazon All Orders report (tab-separated) |
| shopify-orders-sample.csv + shopify-products-sample.csv | Iron & Oak Fitness | Shopify orders and products exports |
| etsy-order-items-sample.csv | Little Gem Studio (jewelry) | Etsy Order Items download |
| tiktok-orders-sample.csv | GlowLab (beauty gadgets) | TikTok Shop order export |
| my-shop-spreadsheet-sample.xlsx | Bloom & Bark (eco pet products) | A seller's own Excel sheet with Sales and Stock tabs |
| *-stock-sample.csv | | Simple stock lists to upload after a sales file |

The app can also generate fresh copies dated up to yesterday ("Try a sample file" on the import screen).
